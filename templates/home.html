What it does

Six parts, one job: never state a fact it can't cite

01

Free meta-search

SearXNG aggregates Google, Bing, DuckDuckGo and dozens more into one query — self-hosted, so there's no per-search bill.

02

Clean extraction

Raw HTML is stripped down to readable article text before it ever reaches the model — no nav bars, ads, or boilerplate in context.

03

Isolated retrieval

Each question gets its own vector collection, so unrelated research sessions never bleed into each other's context.

04

Enforced citations

The model is instructed to back every claim with a [n] marker — and anything it doesn't cite gets dropped from the reference list automatically.

05

Live pipeline status

Watch the run move through search → scrape → embed → generate → report in real time instead of staring at a spinner.

06

Exportable briefs

One click turns the cited answer into a shareable PDF or DOCX, references section included.
